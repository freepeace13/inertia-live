# Inertia Live

Live Inertia pages driven by Spatie Event Sourcing projections. Declare once on the server which projection changes affect which page props; the package handles broadcasting, subscribing, ordering and reloading.

Status: design phase. See [docs/SPEC.md](docs/SPEC.md).

- Composer: `freepeace13/inertia-live-projections`
- npm: `@freepeace13/inertia-live`
